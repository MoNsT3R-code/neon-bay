# Pepper: Neon Bay

An open-world 3D city game that runs entirely in the browser.

Pepper has just stepped off the bus in Neon Bay, a sun-soaked city of neon hotels, palm trees and very fast cars. Borrow any ride, fly the Sky Hopper, race boats round the harbour, tear up Sunset Ridge in a thunderstorm, and become a legend.

**Version 2.0:** 8 story missions · weather · phone · helicopter · boats · pool hall

## How to play

Clone or download this repo and open `index.html` in a modern browser (Chrome, Edge, Firefox or Safari). You don't need to install or build anything.

## Features

- **Story missions** (yellow markers), **pizza jobs** (blue) and a **street race** (purple)
- **Drive any car** you find, plus taxi fares, a helicopter and boats at the marina
- **Wanted stars**: cops chase you if you cause trouble
- **Nitro and combos**: chain drifts, near misses and big air to earn cash
- **Shops and garage**: outfits and hats at Drip Boutique, cars at Turbo Motors, tuning and saves at Rafi's Garage
- **In-game phone** with contacts, weather, places, map and camera
- **Things to do**: the arcade, Hoop Court, the Neon Cue Club pool hall, Taco Comet, the Neon Needle, Stunt Park and Sunset Ridge
- **Collectibles**: 15 hidden cassette tapes and stunt ramps for airtime bonuses
- **Photo mode** with filters
- Dynamic weather, a day/night clock, radio music and **save games**

## Controls

**On foot**

| Action | Keys |
| --- | --- |
| Walk | WASD |
| Sprint | Shift |
| Jump | Space |
| Look around | Drag the mouse |
| Enter a car | F |
| Use shops / garage | E |

**Driving**

| Action | Keys |
| --- | --- |
| Gas / brake | W / S |
| Steer | A / D |
| Handbrake drift | Space |
| Nitro | N |
| Horn | H |
| Radio | R |
| Taxi fares | T |
| Change camera (chase, hood, cinematic, top-down) | C |

**Sky Hopper (helicopter)**

| Action | Keys |
| --- | --- |
| Fly forward / back | W / S |
| Turn | A / D |
| Up / down | Space / Shift |

**General**

| Action | Keys |
| --- | --- |
| Phone (also answers calls) | Q |
| Map | M |
| Photo mode | P |
| Pause | Esc |

## Tips

- To lose your wanted stars, break line of sight with the cops or drive into the Spray Shack.
- Drifting refills your nitro.
- Crashing drops your combo, so bank it before you hit anything.
